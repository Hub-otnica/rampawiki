# Where Dogs Run

## Kratek opis

Where Dogs Run je umetniški kolektiv, ustanovljen leta 2000 v Jekaterinburgu. V sedanji zasedbi ga po uradnih predstavitvah sestavljajo Natalia Grekhova, Alexey Korzukhin in Olga Inozemtseva, njihova praksa pa združuje video, robotiko, hibridne instalacije, performans in DIY pristope ter pogosto obravnava znanstvene probleme, kot so strojno učenje, virtualno modeliranje in kemična komunikacija med bio- in kibernetskimi sistemi.

## Področja dela

- tehnološka umetnost
- robotika
- hibridne instalacije
- bio-kibernetski sistemi
