# Archean Memory Farm

## Kratek opis

`Archean Memory Farm` je projekt kolektiva Where Dogs Run, ki iz lastnosti magnetotaktičnih bakterij razvija model umetnega geološkega spomina oziroma počasnega bio-geo-kibernetskega računalnika. Delo je bilo producirano v okviru projekta S+T+ARTS in the City pri Kersnikovi v sodelovanju z laboratorijem BioTehna.
